🌐 HTML5 & CSS3 trong Web Tĩnh

Nền tảng giao diện cho bài thực hành DevOps Portfolio

Khái niệm & Vai trò:

  • HTML5: Xây dựng cấu trúc trang web chuẩn ngữ nghĩa (semantic structure).
  • CSS3: Thiết kế giao diện hiện đại, responsive trên mọi thiết bị máy tính và điện thoại.
  • Web tĩnh (Static Web): Không cần server backend hay cơ sở dữ liệu phức tạp, cực kỳ phù hợp để lưu trữ trên GitHub Pages với tốc độ tải trang nhanh và bảo mật cao.
