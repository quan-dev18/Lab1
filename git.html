🐙 Git & Version Control

Hệ thống quản lý phiên bản phân tán (Distributed VCS)

Lệnh Git thường dùng trong DevOps:

git init: Khởi tạo repository cục bộ
git add .: Đưa các tệp thay đổi vào Staging Area
git commit -m "...": Ghi nhận snapshot thay đổi vào lịch sử
git push origin main: Đẩy mã nguồn lên kho từ xa để kích hoạt CI/CD
  • Tracking: Theo dõi toàn bộ lịch sử thay đổi của từng dòng code.
  • Branching: Phân nhánh linh hoạt (`main`, `gh-pages`, `feature/...`).
  • Rollback: Dễ dàng quay lại trạng thái trước khi có lỗi bằng `git revert`.
