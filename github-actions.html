⚙️ GitHub Actions Workflow

Nền tảng tự động hóa CI/CD tích hợp trực tiếp trên GitHub

Thành phần chính trong GitHub Actions:

  • Workflows: Luồng tự động hóa được định nghĩa qua file YAML trong thư mục .github/workflows/.
  • Events (Triggers): Sự kiện kích hoạt workflow (ví dụ: push, pull_request, workflow_dispatch).
  • Jobs: Tập hợp các bước (steps) chạy trên cùng một máy ảo (runner: ubuntu-latest).
  • Actions: Các tác vụ được đóng gói sẵn từ cộng đồng (ví dụ: actions/checkout@v4, peaceiris/actions-gh-pages@v3).
